# Student Academic App v1.0.0 - Release Notes

## APK Download
- Release: `app-release.apk` (SHA256: D7986F35...)
- Debug: `app-debug.apk` (SHA256: FC9097AD...)

## What's New
- Initial release of Student Academic App
- Role-based authentication (Student, Teacher, Parent)
- Email verification flow
- Group management with invite codes
- Assignment submission with file validation
- Notes and submission kit management
- JWT access (15m) + refresh (7d) tokens
- Security headers and rate limiting

## Installation
1. Download `app-release.apk` from the Releases page
2. Enable "Install from unknown sources" in Android settings
3. Open the APK file to install
4. Launch the app and register your account

## Requirements
- Android 5.0 (API 21) or higher
- Internet connection for API calls
- Camera permission (for future features)
